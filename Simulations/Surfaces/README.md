# Directory Structure

## Facet directories
The highest level directories here are organized by decimeter facet size. So a facet size of 2 meters corresponds to F020.

## Hurst exponent directories
These are one level below the facet size directories.

Directories of surfaces are organized by Hurst exponent. A hurst exponent of 0.4 corresponds to H40. A hurst exponent of 0.05 corresponds to H05.

## RMS Height directories
These are one level below the Hurst exponent directories.
